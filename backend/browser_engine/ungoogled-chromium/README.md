# ungoogled-chromium

去掉 Google 集成、遥测与后台服务的 Chromium 补丁集。**它是基线，不是反检测内核。**

## 怎么拿

官方只有一个构建索引站，没有统一发布页：

- 索引站：<https://ungoogled-software.github.io/ungoogled-chromium-binaries/>
- Windows 64-bit 版本页里列出多个贡献者的构建，需要人工挑一个

因为来源不唯一，档案里登记为 `manual`：控制台只给链接，不代下。下载后解压到 `<版本号>/`，主程序是 `chrome.exe`。

## 什么时候选它

- 需要一条「什么都没改」的干净基线，用来对比某个补丁到底有没有用
- 环境禁止遥测与 Google 服务
- 需要 32 位 / ARM 这类商业内核不提供的构建

## 什么时候别选

- 目标是反爬/风控站点 —— 这套不含任何反检测改造，基本过不去
- 生产环境需要可信任制品 —— 官方原话是社区构建、**不保证真实性与可复现性**

## 已知注意点

- 每个版本的构建者不同，选择前先看该版本页里的提交者与说明
- 资产名与 `fingerprint-chromium` 的产物高度相似（都叫 `ungoogled-chromium_*`），别混
- 没有 sha256 公示，归档时建议自己算一份记进档案
